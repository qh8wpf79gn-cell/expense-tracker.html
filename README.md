# Expense Tracker

A smart personal expense tracker with AI-powered receipt analysis. Track spending, analyze receipts with vision AI, and manage your budget with detailed insights.

**[Start Tracking ✨](https://qh8wpf79gn-cell.github.io/expense-tracker/expense-tracker.html)**

## Features

- 💰 Log expenses with categories and descriptions
- 📸 AI-powered receipt photo analysis using Claude Vision
- 📊 Real-time expense charts and spending trends
- 🏷️ Categorized expense tracking (Food, Transport, Shopping, etc.)
- 📈 Monthly and category-based analytics
- 🎯 Budget goals and spending insights
- 💳 Transaction history with detailed breakdowns
- 🌙 Dark mode support
- 📱 Fully responsive design

## Usage

1. Enter your Claude API key
2. Add expenses manually or upload receipt photos
3. Categorize your spending
4. View analytics and spending trends
5. Track budget goals and monthly progress

## Receipt Analysis

Upload a photo of your receipt and the AI will:
- Extract items and costs automatically
- Categorize expenses intelligently
- Add entries to your tracker
- Calculate totals and insights

## Requirements

- Claude API key from [Anthropic](https://console.anthropic.com)
- Browser with file upload support
- (Optional) Receipt photos for automatic analysis

## Tech Stack

- HTML5, CSS3, JavaScript
- Claude API (Vision + Haiku models)
- Chart.js for analytics and visualization
- Client-side storage
- No backend required
